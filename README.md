# Projeto Aplicado I — Preços de Combustíveis no Brasil

Projeto individual desenvolvido para a disciplina **Projeto Aplicado I** do curso de Ciência de Dados.

## Tema

Análise exploratória da variação dos preços de combustíveis no Brasil, com foco em gasolina comum, etanol hidratado e diesel S-10.

## Objetivo

Investigar como os preços dos combustíveis variaram entre regiões, estados e períodos do Brasil. O recorte planejado é de 2019 a 2024.

## Fonte dos dados

Os dados são da Agência Nacional do Petróleo, Gás Natural e Biocombustíveis (ANP), disponibilizados como dados abertos.

- [Série Histórica de Preços de Combustíveis e de GLP](https://www.gov.br/anp/pt-br/centrais-de-conteudo/dados-abertos/serie-historica-de-precos-de-combustiveis)
- [Informações sobre o Levantamento de Preços](https://www.gov.br/anp/pt-br/assuntos/precos-e-defesa-da-concorrencia/precos/precos-revenda-e-de-distribuicao-combustiveis)

Os dados representam preços coletados semanalmente em postos selecionados pela pesquisa da ANP. Por se tratar de uma amostra, eles não representam todos os postos e municípios brasileiros.
